Orbit Privacy Policy / 隱私權政策

Last updated / 最後更新：2026-09-28

繁體中文

Orbit 是 macOS 上的本機資料夾空間探索與整理工具。只有在你選擇資料夾後，它才會讀取該位置的檔名、大小與中繼資料，以建立空間圖與檔案清單。尋找重複檔案或核對整理操作時，Orbit 會在此 Mac 上讀取候選檔案的內容並計算雜湊值。它也會讀取磁碟區容量以顯示可用空間。Orbit 不會將這些資料傳送到開發者伺服器。

Orbit 在應用程式支援資料夾保存你授權位置的安全範圍書籤、名稱與最近掃描摘要。空間時間軸最多保留最近 60 次掃描，包含授權位置路徑、掃描時間與設定、容量，以及最多 128 個第一層資料夾的名稱、路徑、容量與檔案數；這些紀錄只保存在本機。搬移或移至垃圾桶的操作會留下本機紀錄，其中可能包含來源及目的地路徑、檔案識別雜湊、操作狀態與錯誤，以便檢視或嘗試復原。外觀與掃描偏好設定保存在此 Mac 的應用程式專屬設定中。完整掃描樹及暫存整理清單只在應用程式執行期間保留。你若選擇匯出掃描報告，報告會存到你選的位置，可能包含檔名及路徑；分享前請自行檢查。

可選的專案線索分析只將最多 48 個截短的檔案或資料夾名稱提供給 Mac 上的 Apple Foundation Models，用來推測可能的專案用途；不以此功能讀取檔案內容。這項功能的可用性取決於 Apple Intelligence 的裝置與系統狀態。Orbit 不建立帳號、不含廣告或開發者分析服務、不提供跨裝置同步，也不透過開發者伺服器收集資料。macOS、Apple Intelligence 或你自行設定的系統備份可能各有處理方式。

English

Orbit is a local macOS tool for exploring and organizing space in folders. After you choose a folder, it reads filenames, sizes, and metadata there to build the space map and file lists. When finding duplicates or verifying an organization action, Orbit reads candidate file contents and computes hashes on this Mac. It also reads volume capacity to display available space. Orbit does not send this data to a developer server.

Orbit stores security-scoped bookmarks for locations you authorize, their names, and recent scan summaries in Application Support. The space timeline retains up to 60 recent scans, including the authorized location path, scan time and settings, byte totals, and names, paths, sizes, and file counts for up to 128 immediate child folders. These records stay on this Mac. Local move and Trash journals may contain source and destination paths, file identity hashes, operation status, and errors so you can inspect or attempt to undo an action. Appearance and scan preferences are stored in this Mac's app-private settings. The full scan tree and temporary review list remain in memory while the app runs. If you export a scan report, it is saved where you choose and may contain filenames and paths; review it before sharing.

Optional project-clue analysis gives up to 48 shortened file or folder names to Apple Foundation Models on your Mac to suggest a possible project purpose; it does not read file contents for that feature. Availability depends on Apple Intelligence device and system status. Orbit has no account, ads, developer analytics service, or app-managed cross-device sync, and does not collect data through a developer server. macOS, Apple Intelligence, and system backups you configure may have separate practices.

Privacy questions: easonwumac@gmail.com.
