繁體中文

Orbit 需要 macOS 26 以上。選擇資料夾後才會掃描。若部分項目無法讀取，請確認檔案權限；尚未下載的雲端檔案不會計入。空間圖顯示邏輯檔案大小，不代表實際佔用或可回收容量。移到垃圾桶後，需清空垃圾桶才會釋出空間。Apple Intelligence 不可用時仍可使用基本掃描與整理。

問題回報、使用協助與功能建議：easonwumac@gmail.com。來信請提供 macOS 與 Orbit 版本、操作步驟及錯誤訊息；寄送截圖或掃描報告前，請先移除私人檔名與路徑。

English

Orbit requires macOS 26 or later. Select a folder to begin scanning. If some items cannot be read, check file permissions; cloud files that have not downloaded are skipped. The space map shows logical file sizes, not physical usage or guaranteed recoverable space. Moving items to Trash releases space only after Trash is emptied. Basic scanning and organization work when Apple Intelligence is unavailable.

For help, bug reports, or feature suggestions, email easonwumac@gmail.com. Include your macOS and Orbit versions, steps, and any error message. Remove private filenames and paths before sending screenshots or scan reports.
