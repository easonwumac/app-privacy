繁體中文

Orbit 需要 macOS 26 以上。選擇資料夾後才會掃描。若部分項目無法讀取，請確認檔案權限；尚未下載的雲端檔案不會計入。空間圖顯示邏輯檔案大小，不代表實際佔用或可回收容量。移到垃圾桶後，需清空垃圾桶才會釋出空間。可選的本機分析需符合 Apple Intelligence 裝置、語言、地區、啟用與模型可用條件；不可用時仍可使用基本掃描與整理。

平面容量圖以矩形面積呈現邏輯大小，選取區塊會與檔案表格同步；可深入資料夾並回到上一層。時間軸從實際掃描開始累積，重新掃描相同位置後即可比較；掃描不完整時不顯示可靠的增減比較。專案卡依檔名線索提出候選群組，同名不代表一定相關。重複檔案請先指定保留副本，再預覽其他副本的整理操作。首版僅允許同一磁碟區內搬移、移至垃圾桶及條件式放回原處；跨磁碟區操作會在改動原始項目前阻擋，請改用 Finder。符號連結會保留但不跟隨其目標。

問題回報、使用協助與功能建議：easonwumac@gmail.com。來信請提供 macOS 與 Orbit 版本、操作步驟及錯誤訊息；寄送截圖或掃描報告前，請先移除私人檔名與路徑。

English

Orbit requires macOS 26 or later. Select a folder to begin scanning. If some items cannot be read, check file permissions; cloud files that have not downloaded are skipped. The space map shows logical file sizes, not physical usage or guaranteed recoverable space. Moving items to Trash releases space only after Trash is emptied. Optional local analysis needs eligible Apple Intelligence hardware, language/region, enablement and an available model. Basic scanning and organization work when it is unavailable.

The flat space map represents logical sizes with rectangular areas. Selecting a block also selects its file-table row; you can explore folders and go back. The timeline begins with actual scans; rescan the same location to compare. Incomplete scans cannot provide reliable change comparisons. Project cards suggest groups from filename clues; matching names do not prove a relationship. For duplicates, choose a copy to keep before reviewing actions for the other copies. Version 1 allows moves, Trash and guarded Put Back only within the same volume. Cross-volume operations are blocked before changing the original; use Finder for those moves. Symbolic links are preserved without following their targets.

For help, bug reports, or feature suggestions, email easonwumac@gmail.com. Include your macOS and Orbit versions, steps, and any error message. Remove private filenames and paths before sending screenshots or scan reports.
